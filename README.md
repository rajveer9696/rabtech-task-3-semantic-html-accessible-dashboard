# RabTech Task 3 – Semantic HTML5 & Accessible Dashboard

## Project Overview

This project is an accessible enterprise-style dashboard built using semantic HTML5, CSS, and JavaScript.

The project focuses on creating a clean structural foundation with proper semantic elements, accessible forms, keyboard-friendly interactions, and an organized DOM hierarchy.

## Features

- Semantic HTML5 structure
- Accessible navigation and page layout
- Dashboard with structured content
- User management interface
- Accessible form controls
- Proper `<label>` associations
- Required form validation
- Accessible modal dialog for adding users
- Keyboard support with `Escape` key
- Responsive and clean UI
- Separate CSS and JavaScript files

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## Semantic Structure

The dashboard uses semantic HTML5 elements including:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<aside>`
- `<footer>`
- `<form>`
- `<fieldset>`
- `<dialog>`

## Accessibility

Accessibility was considered throughout the project:

- Proper labels for form inputs
- `aria-labelledby` used for the modal dialog
- Keyboard support for closing the modal
- Native HTML form validation
- Semantic document structure
- Clear button and input elements
